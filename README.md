# A Better Everyday Life

An interactive, scrolling edition of the Manhattan Institute issue brief [“A Better Everyday Life in New York: 50 Practical Ideas to Renew NYC’s Promise of Opportunity”](https://manhattan.institute/article/a-better-everyday-life-in-new-york-50-practical-ideas-to-renew-nycs-promise-of-opportunity) by John Ketcham and Sean Speer (October 20, 2026).

The brief’s 50 recommendations are placed one at a time on a composite New York block that changes as you scroll. The page also redraws the brief’s evidence, adds a rent-and-childcare paycheck calculator, an all-50 index with filters and a personal list, a glossary, and an eight-question quiz.

Idea text is condensed and reworded from the brief; the brief’s own wording governs. Single self-contained `index.html`; no build step. Serve the folder with any static server, or publish with GitHub Pages.
